## 2024-05-18 - [Accessibility] Dynamic ARIA Labels on Notification Badges
**Learning:** When using components like notification badges that contain dynamic numbers (e.g., unread counts) inside an icon wrapper link, screen readers can announce the visual components redundantly or confusingly if `aria-label` isn't managed correctly. The badge element itslef or internal SVG elements might be read out of context.
**Action:** Use server-side interpolation to add a descriptive `aria-label` directly on the wrapper container that includes both the function and the dynamic content (e.g., `aria-label="Notifiche, <%= count %> da leggere"`), and apply `aria-hidden="true"` to ALL internal visual elements like icons and the number badge `<span>` to guarantee a clean, single announcement.
