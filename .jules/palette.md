## 2024-05-24 - Accessibility and Semantic Elements in EJS Templates
 **Learning:** Discovered that clickable elements functioning as buttons (like `sidebar-overlay`) were using non-semantic `div` tags with only an `onclick` handler, making them invisible to screen readers and inaccessible via keyboard navigation. Additionally, multiple icon-only buttons (like menu toggles and chat send buttons) across partials and pages lacked `aria-label` attributes.
 **Action:** Implemented a standard pattern for converting non-semantic interactive `div` elements by adding `role="button"`, `tabindex="0"`, an appropriate `aria-label`, and an `onkeydown` handler for the 'Enter' and 'Space' keys. Standardized the addition of descriptive `aria-label`s to all icon-only interactive elements to ensure assistive technology can announce their purpose accurately.
