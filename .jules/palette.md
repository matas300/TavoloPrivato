## 2024-03-24 - Accessibility for dynamic badges and icon buttons
**Learning:** When adding ARIA labels to components that have dynamic text (like notification badges with counts in EJS views), interpolating the dynamic value directly into the `aria-label` attribute (e.g., `<a aria-label="Notifiche, <%= count %> da leggere">`) and adding `aria-hidden="true"` to the inner visual elements ensures screen readers read out the count elegantly, instead of getting confused by inner structure and partial hidden elements. For generic icon-only buttons (like menu or send message buttons), providing an Italian translation of the action (e.g., `aria-label="Menu navigazione"`) improves usability for Italian users.
**Action:** When adding ARIA labels to containers with badges, wrap the dynamic server-side output `(e.g., <%= ... %>)` directly within the `aria-label` string. Add `aria-hidden="true"` to any inner icons or text nodes (like the badge span) to prevent redundant announcements. Ensure `aria-label` values are localized matching the app language.
