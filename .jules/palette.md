## 2024-05-23 - Accessibility for Dynamic Icons
**Learning:** When using Lucide icons (`<i data-lucide="...">`), the library dynamically replaces `<i>` tags with `<svg>` tags in the DOM. Therefore, when making icon-only interactive elements or input fields without labels accessible by adding `aria-hidden="true"` to the internal `<i data-lucide="...">`, Playwright automation needs to wait for the SVG replacement and verify the `aria-hidden` attribute on the resulting `<svg>` element. Also, `aria-label`s on containers must dynamically interpolate nested counter badges and hide the inner badge elements to prevent redundant announcements by screen readers.
**Action:** Always add `aria-hidden="true"` directly to the initial `<i>` tags when the parent container has a descriptive `aria-label`. Use `page.wait_for_selector('svg', state='attached')` in Playwright verification scripts to assert on the correctly rendered elements. Interpolate dynamic content directly into parent `aria-label`s.
